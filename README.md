# Library Management System

## Objective
Design a relational database schema for a library management system.

## Tables
- Authors
- Books
- Customer
- Borrowings

## Relationships
- One Author can write many Books.
- One Customer can borrow many Books.

## Concepts Used
- DDL
- Primary Key
- Foreign Key
- Normalization
- ER Diagram

## Tools Used
- MySQL Workbench
- GitHub
